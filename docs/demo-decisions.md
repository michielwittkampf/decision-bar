# Demo decisions

The sample decisions used for the screenshots in the README, for an imaginary office
coffee-ordering app. To put them in the bar, paste this into a Claude Code session with the mod
installed:

```
Put these demo decisions in the decision bar (language: en), in this order:
- Dark mode: Ship dark mode for the night shift.
- Decaf: Show a gentle warning when someone orders their fifth espresso before noon.
- Auth: Let colleagues sign in with the company SSO. And unlock massive rewards if they do; big bear hugs and high fives.
- Milk: Add oat milk as a default option, since it now outsells regular milk two to one.
- Easter egg: Play a tiny trumpet sound for the thousandth order of the month.
```

For the screenshots: agree on Dark mode, disagree on Auth, and the remark "Seven is fine. Be
gentle." on Decaf.
