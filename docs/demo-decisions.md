# Demo decisions

The sample decisions used for the screenshots in the README, for an imaginary office
coffee-ordering app. To put them in the bar, paste this into a Claude Code session with the mod
installed:

```
Put these demo decisions in the decision bar (language: en), in this order:
- Dark mode: Ship dark mode for the night shift.
- Decaf: Show a gentle warning when someone orders their fifth espresso before noon.
- Auth: Let colleagues sign in with the company SSO. And unlock massive rewards if they do; big bear hugs and high fives.
- Milk: Add oat milk as a default option, since it now outsells regular milk two to one.
- Easter egg: Play a tiny trumpet sound for the thousandth order of the month.
```

For the screenshots: agree on Dark mode, disagree on Auth, and the remark "Seven is fine. Be
gentle." on Decaf.

The same set in Dutch, for the README screenshot of the bar in another language:

```
Zet deze demobeslissingen in de beslissingsbalk (language: nl), in deze volgorde:
- Donkere modus: Lever de donkere modus op voor de nachtdienst.
- Cafeïnevrij: Toon een vriendelijke waarschuwing als iemand vóór de middag zijn vijfde espresso bestelt.
- Inloggen: Laat collega's inloggen met de SSO van het bedrijf. En beloon ze daar royaal voor; dikke berenknuffels en high fives.
- Melk: Maak havermelk een standaardoptie, nu die twee keer zo goed verkoopt als gewone melk.
- Easter egg: Speel een klein trompetgeluidje bij de duizendste bestelling van de maand.
```

For the screenshot: akkoord on Donkere modus, niet akkoord on Inloggen, and the remark "Zeven is prima. Be gentle." on Cafeïnevrij.
